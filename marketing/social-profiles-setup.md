## 1. Facebook Page

### Step by step
1. Log in to Facebook (your personal account; it becomes the Page admin, and the Page won't show your name).
2. **Menu (☰)** → **Pages** → **+ Create new Page**.
3. Fill in:
   - **Page name:** `Budget Tracker PH`
   - **Category:** type and pick **App Page**, then add **Software** (and **Personal Finance** if it appears)
   - **Bio:** paste from below
4. Click **Create Page**.
5. **Profile picture:** upload `profile-picture.png`.
6. **Cover photo:** upload `facebook-cover.png`. On a phone FB trims the sides, so check that the headline is still readable and drag it if needed.
7. **Edit details / About:** fill in the fields from the table below.
8. **Add button** → **Sign up** (or **Use app**) → link = website link (`utm_source=facebook`).
9. **Username:** Settings → Page setup → **Username** → `budgettrackerph`.
10. Publish the **first post** (below), then **⋯ → Pin post**.
11. Invite friends to like the Page: **⋯ → Invite friends** (start with ~50 people you know).

## 2. TikTok

### Step by step
1. Install TikTok. If you already have a personal account: **Profile → ☰ → Add account** (keep the brand separate from your personal account).
2. Sign up with the brand email (`budgettrackerph@gmail.com`).
3. **Username:** `budgettrackerph`
4. **Profile → Edit profile:**
   - **Name:** `Budget Tracker PH`
   - **Bio:** paste from below
   - **Photo:** `profile-picture.png`
5. **Switch to a Business Account:** Profile → ☰ → **Settings and privacy** → **Account** → **Switch to Business Account** → category **Software & Apps** (or **Personal Blog** if it's not listed).
6. **Website link:** Edit profile → **Website** → website link with `utm_source=tiktok`. If TikTok says you need more followers for a bio link, write "Link sa FB page namin 👆" in the bio for now.
7. Follow ~20 PH personal-finance and couple creators, and leave **genuine** comments on their videos for a few days before you post. This warms up the account.
8. Post TikTok **#1** from `week-01-content.md` on Monday.
